# Comment Category Prediction Challenge

This project was developed for a Kaggle competition focused on predicting the category of user comments using machine learning and NLP techniques.

## Problem Statement
Build a predictive model that determines the final category assigned to each comment using textual, numerical, and categorical features.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- NLP
- Jupyter Notebook

## Workflow
1. Data Cleaning
2. Feature Engineering
3. Text Preprocessing
4. Model Training
5. Prediction & Submission

## Files
- `comment_category_prediction.ipynb` → Main notebook
- `submission.csv` → Kaggle submission file
